# Cursor project config

This folder is for [Cursor](https://cursor.com) IDE settings scoped to this repo.

- **`rules/`** — project rules (`.mdc` or as documented in Cursor). Add files here so the whole team shares the same AI guidance.
- **`next-steps.md`** — site roadmap: shipped waves 0–8 (historical) and the current support/UX phase.
- **Changelog policy** — root [`CHANGELOG.md`](../CHANGELOG.md) points at `content/changelog/`; every `templates/*.md` change needs a matching entry in the same commit.

Long-term memory and daily scratchpads solve **different** problems. Mixing them is how you end up with a file nobody dares to edit.

## Session notes

Session notes are **disposable context**: what happened today, open threads, half-baked ideas. They should be easy to append and safe to ignore later.

## Long-term memory

Long-term memory is **slow food**: confirmed facts, stable preferences, things you want the agent to assume true until superseded.

## Rule of thumb

If you would not put it in a **README for a teammate**, it probably should not live in long-term memory yet. Promote after confirmation, not on first impulse.
